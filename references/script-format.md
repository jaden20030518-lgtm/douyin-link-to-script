# 脚本格式参考

参考脚本常见的成稿形态是“一个视频一个小节”，只保留角色台词：

```text
1）团购向视频
对标视频：链接
标题：一句话标题
A：带冲突的问题？
B：先回应，再给出活动信息。
A：追问适用范围或购买方式。
B：从视频左下角购买，到店看完衣服再决定。
```

只有用户明确要求时，才补充以下标记：

- `【第一视角】`、`【一镜到底】`、`【特写】`、`【插入空镜】`
- `【花字】`、`【字幕】`、`画外音：`、`（变音）`
- `【待确认】`、`【已拍】`、`【需补拍】`

脚本默认只写角色台词。动作可作为台词前的极短括号补充，例如“（拿起衣服）”；不要默认添加镜头、花字、机位或剪辑备注。
